# Set-ClickUpKeyResult

## SYNOPSIS

Update a ClickUp key result.

## SYNTAX

### __AllParameterSets

```
Set-ClickUpKeyResult [-KeyResultID] <string> [[-Name] <string>] [[-Note] <string>]
 [[-Owners] <ulong[]>] [[-Type] <string>] [[-StepsStart] <ulong>] [[-StepsEnd] <ulong>]
 [[-StepsCurrent] <ulong>] [[-Unit] <string>] [[-TaskIDs] <string[]>] [[-ListIDs] <ulong[]>]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Update a ClickUp key result.

## EXAMPLES

### EXAMPLE 1

Set-ClickUpKeyResult -KeyResultID 947d46ed -StepsCurrent 5 -Note 'Target achieved'
Update a ClickUp key result with ID "947d46ed".
